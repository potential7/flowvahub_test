# Flowvahub - Flutter Competition Entry

A Flutter application with Supabase authentication and a gamified referral system.

## 🎯 Features

- ✅ Email/Password Authentication
- ✅ Splash Screen with Auto-Login
- ✅ Beautiful Glassmorphism UI
- ✅ 3D Product Display
- ✅ Countdown Timer
- ✅ Referral System UI
- ✅ Social Sharing

## 📦 Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/flowvahub.git
cd flowvahub
```

2. Install dependencies
```bash
flutter pub get
```

3. Configure Supabase (see SETUP.md)

4. Run the app
```bash
flutter run
```
